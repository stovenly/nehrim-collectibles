# Nehrim Collectibles Tracker

**<https://stovenly.github.io/nehrim-collectibles/>**

Drop a Nehrim save (`.ess`) on the page and get back what you still have to
collect, as a list and as pins on the world map:

- Magic Symbols (100)
- Sparks of Fire Caps (89)
- Ice Claws (158)
- Almanacs of Conjuration (22)
- Potions of Encumbrance (27)

The save never leaves your machine — it is read in the browser, and nothing is
uploaded anywhere.

Results assume an unmodded Nehrim. Mods that move, add or remove collectibles
can make them wrong; the page warns you when a save loads plugins it does not
recognise.
